# Safety Quest テスト仕様書

## 1. 目的

現行MVPが、ナレッジ、スキル、実績の登録、ポイント評価、一覧検索、ダッシュボード、月次レポート、DB schema検証を期待どおり実行できることを確認する。

## 2. テスト範囲

| 区分 | 対象 |
|---|---|
| 単体 | KP/SP/AP判定、EP集計、レベル計算、月次判定、検索条件 |
| 画面 | ログイン、ダッシュボード、ナレッジ登録、獲得スキル、実績登録、一覧、レポート、設定 |
| 永続化 | `localStorage` 保存、リロード後の保持 |
| DB | Prisma schema検証 |
| 非機能 | レスポンシブ、主要画面表示、文言整合性 |

## 3. 合否基準

- `npm run build` が成功する。
- `npm run db:validate` が成功する。
- 主要画面でJavaScriptエラーが発生しない。
- 登録したKP/SP/APがEP、一覧、ダッシュボード、レポートに反映される。
- 旧文言であるヒヤリハット、改善クエスト、BOSS、週次通知、記録してAI分析が画面に残っていない。

## 6. E2Eテスト

### E2E-001 標準フロー

1. ログインする。
2. ナレッジを登録する。
3. 獲得スキルを登録する。
4. 実績を登録する。
5. 一覧で全て、ナレッジ、スキル、実績を切り替える。
6. ダッシュボードでEPと推移を確認する。
7. 月次レポートを作成する。
8. レポートにナレッジ、スキル、実績、KP/SP/AP、次のステップが含まれることを確認する。

期待結果: 登録内容とポイントが各画面に一貫して反映される。

### E2E-002 年月指定フロー

1. 獲得スキルで過去月を指定して登録する。
2. 実績登録で別の過去月を指定して登録する。
3. 一覧で登録年月が表示されることを確認する。
4. ダッシュボードの今月集計に過去月分が含まれないことを確認する。

期待結果: 指定年月に応じて月次集計対象が分かれる。

### E2E-003 レポート保存フロー

1. 月次レポートを作成する。
2. 同じ月でもう一度作成する。
3. リロードする。
4. 年月を選択して表示する。

期待結果: 同じ月のレポートは1件として保持され、リロード後も確認できる。
